# Welcome to Discussions 👋

This is the friendly front door. If you are new to FED-OS Muse Skills, start here.

## What is this place?

A fleet of small, auditable skills for AI Muse agents — one repo per skill. Each
skill is a `SKILL.md` playbook, a `manifest.json`, a `README.md`, and a `scripts/`
directory, and each one does exactly one job. You can read any of them in one
sitting.

## Where should I post?

- **💬 General** — say hi, ask a vague question, share what you built.
- **🙋 Q&A** — a specific "how do I…" that has an answer. Mark the reply that
  solved it so the next person finds it.
- **💡 Ideas** — a new skill, or a new capability for an existing one. Rough ideas
  are welcome; they do not need to be fully formed.
- **🐛 Show and tell** — something you made with a skill. Screenshots welcome.
- **📣 Announcements** — maintainers only; releases and breaking changes.

## The one rule

Be kind, assume good faith, and critique the work rather than the person. This
project exists because a long conversation got corrected by people willing to say
"this is wrong, and here is why." That is the energy we want. Full text:
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## The one thing not to post

**Secrets.** No tokens, no client IDs, no private URLs, no `.env` contents. If a
bug only reproduces with a credential, describe the *shape* of the credential, not
its value. If you think a credential leaked into this project, stop and follow
[SECURITY.md](SECURITY.md) instead of posting publicly.

## Before you post

- Search existing discussions and issues — someone may have asked already.
- Read [FAQ.md](FAQ.md) — it answers the questions people actually ask.
- For a bug or a feature, an [issue](https://github.com/Git-FED/fed-os-muse-skills/issues)
  is usually a better fit than a discussion.

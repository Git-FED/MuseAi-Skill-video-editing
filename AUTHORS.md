# Authors & Credits

This project is maintained by the Git-FED / FED-OS collective. It exists because a
lot of people wrote the small, unglamorous things — a shell one-liner here, a
footer rule there — that a skill fleet is ultimately made of.

## Lead maintainer

- **Git-FED** — project direction, the "one repo per skill" contract, and the
  shared rules every skill obeys. See [MAINTAINERS.md](MAINTAINERS.md).

## Contributors

Contributions are credited in the repository history and, for substantial work, in
this file. If you have contributed and are not listed, open a pull request — this
list is maintained by hand and is never complete.

- The FED-OS community — audits, corrections, and the "same lens" reviews that
  shaped the shared rules.

## How to be credited

We credit by the name and handle you choose. Add yourself in the same pull request
as your contribution, or ask a maintainer to do it for you. We do not require a
real name, a legal identity, or any personal data beyond what you want shown.

## Third-party work

This project depends on tools and standards built by others. Where a skill wraps
an external binary (for example `ffmpeg`, `jq`, `wrangler`), that tool remains the
property of its authors and is governed by its own license. See
[NOTICE.md](NOTICE.md) for the list of external dependencies and their licenses.

## A note on the referral

Some links in this project pay the maintainer (a referral or affiliate link). Every
such link carries a machine-readable `"disclosure": "referral"` field and a
plain-language disclosure line next to it. Credits and compensation are kept
separate on purpose: nobody is listed here because they paid, and nothing is
recommended here because it pays.

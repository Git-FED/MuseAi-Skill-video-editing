A skill is a folder. A SKILL.md is the product. No build step, no package manager, no config — drop it in and the agent does the work. This fleet ships five production skills plus the rules that keep them honest.

The rules these skills encode

The guardrails the whole fleet shares.

No HTML in skill repos

A skill's output is a plan, not markup.

No live credentials

Client IDs, keys, and OAuth state live server-side — never in a tracked file or a URL.

Canonical links only

Reference platforms by handle; resolve to a live URL at render time.

Disclose referrals

Any link that pays you carries a plain-language disclosure above it.

No fake gates

A client-side "I am 18+" checkbox is not verification. Gate the content server-side, or don't claim to gate.

Enforced hashes

release.yml refuses to publish if manifest.json:files doesn't match the tree.

Install a skill

Download → verify hashes → drop it in.

# 1. download the release
curl -LO https://example.org/fed-os-muse-skills/releases/download/v1.0.0/muse-footer-layout-v1.0.0.zip

# 2. verify hashes against manifest.json:files, then drop it in
unzip muse-footer-layout-v1.0.0.zip -d ~/workspace/custom-skills/

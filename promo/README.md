# Promotion Images

A coordinated set of four square graphics for the fleet’s shared engineering rules.
The images use the project’s midnight, cyan and violet palette with a consistent
editorial developer-tool style.

| File | Rule | Caption / alt text |
| --- | --- | --- |
| `promo-1-one-repo-per-skill.jpg` | One repo per skill | One repo per skill. Small, self-contained, ready to ship. |
| `promo-2-no-credentials.jpg` | No live credentials | No credentials in the repo. Secrets stay out of source control. |
| `promo-3-canonical-links.jpg` | Canonical links only | Canonical links only. Store handles. Resolve URLs at runtime. |
| `promo-4-no-fake-gates.jpg` | No fake gates | No fake gates. A checkbox is not a lock. |

These are finished, high-resolution images with the captions already included.
They are not generated from local source illustrations by a script; update the
final image files directly when the artwork needs to change. Use the caption from
the table as the alt text when posting an image in a context that supports it.

The assets are shared under the repository’s MIT license. Please do not add
claims the project cannot back up, such as “verified,” “secure,” or “gated.”

# Pricing

## The honest answer: the software is free

Every skill in this repository is MIT-licensed and free to use, fork, and ship.
There is no paid tier, no license key, no "pro" version held back, and no feature
that unlocks if you pay. If you read [LICENSE](LICENSE), that is the whole deal.

This page exists because people ask "how do I support this?" and because a project
that takes money should say plainly what the money does and does not buy.

## What funding is

Funding is a thank-you. It is optional, it is recurring only if you choose, and it
never changes what the software does.

The canonical funding handles are declared once in
[.github/FUNDING.yml](.github/FUNDING.yml):

| Platform | Handle |
| --- | --- |
| GitHub Sponsors | `Git-FED` |
| Ko-fi | `fedpromptly` |
| Patreon | `fedpromptly` |
| Buy Me a Coffee | `fedpromptly` |

Those are **handles**, not checkout URLs. A handle is stable and carries no
session, no amount, and no credential; the platform resolves it to a real page at
render time. If you ever see a raw checkout URL in this repository, that is a bug —
open an issue.

## What funding does not buy

- **It does not buy priority.** Issues are triaged by severity, not by who paid.
- **It does not buy influence.** A sponsor's feature request is a feature request,
  weighed the same as anyone else's.
- **It does not buy access.** There is no sponsors-only build, no private repo, no
  early channel that changes the code you get.
- **It does not buy silence.** Disclosures stay, corrections stay, and a bad idea
  from a sponsor is still a bad idea.

## Disclosure

Some links in this project — including the Muse sign-up link — are **referral
links**: if you use them, the maintainer may earn a commission or a credit. Every
such link carries a machine-readable `"disclosure": "referral"` field and a
plain-language line next to it. Links that do not pay do not carry that field.

This is stated here, in the [README](README.md), and in the reference data for each
skill that emits links, because a disclosure that only appears in one place is a
disclosure that is easy to miss.

## Why no "gated" premium content

You will not find a section of this repository that says "members only" behind a
checkbox. A checkbox is not a gate. If content ever genuinely needs to be
restricted, it will be restricted on the server, and until then it is simply not
shipped as "premium." Pretending to gate something is worse than not gating it,
because it teaches people to trust a lock that is not there.
